## ✨ Why Sahkarmi

- **🆓 Free from the first minute.** Free AI models are built in. No account, no card, no setup.
- **🖥️ It really does the work.** Coworkers use your PC, your browser and your files, not just chat.
- **✋ You stay in charge.** Payments, messages to customers, publishing and deleting wait for your OK.
- **🔒 Private by design.** Everything runs on your computer. There is no Sahkarmi cloud account.
- **🤝 A team, not one bot.** Each coworker has its own role, browser, memory and task queue, and they pass work to each other.

## 🚀 Get started in 2 minutes

1. **Download** the installer from [GitHub Releases](https://github.com/ganguydhrubo/Sahkarmi/releases/latest)
   or install from the [Microsoft Store](https://apps.microsoft.com/detail/9PD6BP3NGVST).
2. The GitHub installer is not code-signed yet, so Windows SmartScreen warns. Choose **More info → Run anyway**.
   (The Microsoft Store version has no warning.)
3. On first launch keep **OpenCode (free, built in)** selected and click **Continue**.
4. Pick a coworker and type what you need, in plain words.

Or with [Scoop](https://scoop.sh/):

```powershell
scoop bucket add sahkarmi https://github.com/ganguydhrubo/scoop-sahkarmi; scoop install sahkarmi
```

| Platform | Status |
| --- | --- |
| Windows 10 / 11, 64-bit | ✅ Built and tested |
| macOS, Linux | ⏸️ Paused until tested on real hardware; build from source meanwhile |

Full steps, checksums, troubleshooting and uninstall: **[sahkarmi.site/install.html](https://sahkarmi.site/install.html)**.

## 👥 Your team

- **Nine coworkers to start**, with editable names and roles: an orchestrator, accounts, sales,
  support, research, content, code, operations and security.
- **A marketplace of 175 ready-made coworkers**: accountant, HR manager, shop manager, tutor,
  designer, developer and many more. [See them all](https://sahkarmi.site/coworkers/).
- **Team runs**: one job split across several coworkers. A run pauses when it needs your approval
  and carries on from the last finished step, even after the app was closed.

## 🛡️ Staying in charge

- **Approvals inbox.** Coworkers stop and ask before payments, messages to customers or vendors,
  publishing, form submissions, deleting data or sharing personal data. Your answer goes back to them.
- **Take over** any coworker's browser for logins, OTPs, CAPTCHAs and payment pages; its tools pause while you drive.
- **Desktop control is permission-based.** One coworker drives the desktop at a time, and typing into
  password fields and Windows sign-in prompts is refused.
- **Phone & Telegram.** Approve from your phone through your own Tailscale, or in the one Telegram chat you paired.

> [!WARNING]
> Development preview. Coworkers run through local agent runtimes with full local access (files,
> commands, network, the built-in browser). Every shell command goes through the approval rules in
> the app, but stopping before a payment, a customer message, publishing or a web form still relies
> on the model following its instructions. Run only tasks you trust, keep backups, and never share
> card details or OTPs with a coworker.

## 🤖 AI providers

Free AI works out of the box. Connect a paid plan only if you want to.

| Provider | How Sahkarmi uses it | Cost |
| --- | --- | --- |
| **OpenCode (built in)** | Bundled with the installer. Free models, no login. When one free model hits its limit, Sahkarmi moves to the next. | Free |
| **Claude** | The Claude CLI with Sahkarmi's own sign-in (Settings → AI and models → Connect), kept separate from your Claude Code account. | Your plan |
| **ChatGPT (Codex)** | Your installed Codex CLI and its ChatGPT login. | Your plan |
| **Google Antigravity** | Google's Antigravity agent, downloaded on Connect after you accept Google's terms. Log in with Google or use an AI Studio key. | Your Google plan |

Sahkarmi finds installed CLIs and reuses their login (Claude has its own, see above). It never copies tokens.
If a paid provider stops answering or runs out of quota, the message moves to the free model with a note in the chat.

## 🔐 Privacy

- No Sahkarmi account, no cloud service, no tracking. The app asks once whether it may add this PC
  to an anonymous daily user count; nothing is sent unless you say yes (change it in Settings → About).
- What a coworker works on goes only to the AI provider you chose for it, under that provider's terms.
  Telegram, Composio and Tailscale are used only if you connect them.
- Your data stays in `%USERPROFILE%\Sahkarmi` and `%APPDATA%\Sahkarmi`. Local servers listen on
  this PC only (127.0.0.1); phone access comes through your own Tailscale, never a public port.

Full policy: [sahkarmi.site/privacy.html](https://sahkarmi.site/privacy.html).
Security issues: [SECURITY.md](SECURITY.md) (private reporting).

## 🛠️ Development

Requires [Bun](https://bun.sh/) 1.3.11 and Node.js 22.12 or newer.

```bash
git clone https://github.com/ganguydhrubo/Sahkarmi.git
cd Sahkarmi
bun install --frozen-lockfile
bun run fetch:opencode   # bundled free-model runtime for your platform
bun run dev
```

To reset only the local development state, quit the dev app and run `bun run dev:reset`.

<details>
<summary><strong>All commands</strong></summary>

| Command | Purpose |
| --- | --- |
| `bun run dev` | Start Electron with renderer hot reload. |
| `bun run check` | Biome, both typechecks, offline tests, the browser smoke test and the production build. |
| `bun run test` / `bun run test:backend` | Vitest suites (all offline, with fake agent servers). |
| `bun run test:browser` | Built-in browser smoke test. |
| `bun run codex:doctor` | Check the real Codex CLI handshake without starting a paid turn. |
| `bun run package:win:verify` | Build and verify the Windows x64 app (fuses, ASAR, launch). |
| `bun run dist:win` / `dist:mac` / `dist:linux` | Local installers. |
| `bun run release:patch` | Bump version and changelog, commit and tag the next patch release. |

</details>

<details>
<summary><strong>Architecture</strong></summary>

```text
Electron main
├── local Codex App Server process over stdio JSONL
├── local Claude Agent SDK session over stream JSON
├── ACP agents (bundled OpenCode, Google Antigravity) over stdio
├── persistent bot and mailbox stores
├── secure typed IPC handlers
└── sandboxed WebContentsView browser host
    ↕ typed preload bridge
SolidJS renderer
```

- `src/main`: Electron lifecycle, window security, local protocol, IPC registration, updates.
- `src/backend`: provider adapters, persistence, message scheduling, approvals, the browser host.
- `src/preload`: the typed `window.sahkarmi` API only.
- `src/renderer`: the SolidJS interface. `src/shared`: process-boundary contracts.

Releases are tag-driven: pushing a version tag builds the Windows installer in GitHub Actions and
publishes it with checksums, SBOM and build provenance. Installed apps update themselves from
GitHub Releases. See [docs/RELEASING.md](docs/RELEASING.md).

</details>
